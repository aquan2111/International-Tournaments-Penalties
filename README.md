# International-Tournaments-Penalties

This repository compares penalties taken during some recent international men and women tournaments.

This includes the latest two European Championships and World Cups for both men and women.

Data: [StatsBomb Open Data](https://github.com/statsbomb/open-data).

The code can be found in the [Jupyter Notebook](international-tournaments-penalties.ipynb).

The report can be found in the [PDF](International-Tournaments-Penalties-Report.pdf).
